## 핵심 결과

### 1. 평가 지표 NDL Score — 가중치를 팀 성적으로 학습

득점·효율·플레이메이킹·수비·승리기여 5개 축으로 점수가 **어디서 왔는지 보이는** 지표를 만들고,
처음에 감으로 정한 가중치를 팀 득실차로 학습시켰습니다.

- 학습·검증에 쓰지 않은 **2016~2024 시험 구간 9개 시즌 전부 개선**(설명력 0.878 → 0.922)
- **All-NBA 일치율 65.8%** — WS 64.5%, PER 57.1%, BPM 38.6%보다 높음
- 제약 없이 학습하면 승리기여 축이 83%를 가져갔습니다. 그 축은 팀 성적에서 역산한 WS·VORP로
  만들어져 "팀 성적으로 팀 성적을 맞히는" 구조였기에, 축마다 5~40%로 제한했습니다

### 2. 다음 시즌 선수 예측 — 오차 4.61 → 4.03

| 모델 (2016-17 이후 시험, 2,576개) | 오차(MAE) | 상관 |
|---|---|---|
| 작년 성적 그대로 | 4.61 | 0.730 |
| 최근 3시즌 가중평균 | 4.40 | 0.742 |
| **+ 평균회귀·나이·기량 구간·유망주 성장·결장 보정** | **4.03** | **0.772** |

- 평균회귀는 **기량 구간마다 달랐습니다**. 80점 이상은 6%, 50점 미만은 54%만큼 평균 쪽으로 돌아옵니다
- 부상 시즌은 점수가 눌려 있어 **결장한 경기만 되살려** 예측합니다(아데토쿤보 36경기 62.1 → 보정 약 73)
- 숫자 하나는 평균 경로라 크게 성장할 선수를 놓칩니다. 그래서 **다음 시즌 80% 범위**와
  비슷한 과거 선수 30명으로 구한 **5년 내 80점 도달 확률**을 함께 보여줍니다

| 80점 도달 확률 예측 (2010-11~2020-21 검증) | 5~15% | 15~30% | 30~50% | 50~80% | 80~100% |
|---|---|---|---|---|---|
| 실제 도달 | 8% | 24% | 36% | 53% | 93% |

### 3. 팀 성적 예측 — 11개 시즌 전부 기준선보다 정확

선수 예측을 개막 로스터 단위로 모아 팀 공격·수비 레이팅과 승수를 예측했습니다. 시즌 시작 시점에
알 수 없는 정보(실제 출전시간, 시즌 중 트레이드)는 쓰지 않았습니다.

| 모델 (2016~2026, 330팀-시즌) | 승수 오차 | 순레이팅 오차 | 상위 6팀 적중 |
|---|---|---|---|
| 작년 팀 성적 그대로 | 8.4승 | 3.37 | 7.8 / 12 |
| **로스터 NDL 예측** | **6.7승** | **2.72** | **8.4 / 12** |
| *(참고) 선수 성적까지 안다면* | *3.1승* | *1.15* | — |

남은 오차의 대부분은 팀 집계가 아니라 **선수 개개인의 다음 시즌 변화**에서 나옵니다.
2026-27 예측: 동부 보스턴(51.5승)·클리블랜드·디트로이트, 서부 오클라호마시티(65.1승)·샌안토니오·덴버.

## 측정하고 버린 것, 틀렸던 해석

| 시도·가설 | 결과 |
|---|---|
| 팀 환경을 걷어낸 수비 보정 | 개선 +0.002 → 채택 안 함 |
| 비율 대신 개수로 계산 | 축 하나는 좋아졌지만 정보가 겹쳐 전체는 나빠짐 → 채택 안 함 |
| 신인을 드래프트 순번으로 구분 | 1~3순위 말고는 평균과 같음, 팀 오차 변화 없음 → 채택 안 함 |
| 한 해 급등한 스타는 덜 깎자 | 최근 10년엔 오히려 더 떨어짐 → 채택 안 함 |
| "수비는 선수 기록의 합이 아니다" | **틀림.** 그 시즌 기록으론 수비 상관 0.79, 다음 시즌으로 안 이어질 뿐 |

> 실수의 대부분은 두 가지였습니다 —
> **전체 평균 하나만 보고 판단했고, 상수를 데이터에 묻지 않고 직접 정했다.**

## 한계

- 팀 성적 설명력은 공인 지표보다 낮습니다(0.890 vs WS 0.941). 다만 WS는 팀 성적에서 역산한 지표입니다
- 1973-74 이전에는 스틸·블록 기록이 없어 수비 축이 사실상 비어 있습니다
- 90점 도달 확률은 실제보다 낮게 나옵니다. 90점대 시즌이 2010년대 이후 두 배로 늘었기 때문입니다
- 스타의 예측 범위는 좁습니다(적중 68%). 2016년 이후 스타의 다음 해 결장 비율이 27% → 59%로 뛰었습니다
- 시뮬레이션은 슛 위치 기록이 있는 1996-97 이후만 지원합니다

## AI 활용 범위

개발 도구로 Claude Code를 사용했습니다. **코드 작성은 AI가, 무엇을 만들고 무엇을 버릴지 판단하는
것은 제가** 했습니다. 학습·검증·시험 구간을 나눈 검증 체계, 팀 성적에서 역산된 지표의 함정을 알아채고
건 제약, 수치로 효과가 작은 기능을 버린 결정이 그 예입니다.

## 실행

```bash
pip install -r requirements.txt

python data/fetch_all_seasons.py --force   # 77개 시즌 수집·계산 (캐시 사용)
python data/fetch_team_margins.py          # 채점용 팀 득실차
python data/optimize_weights2.py           # 가중치 학습 (제약 조건 3종 비교)
python data/report_final.py                # 학습 전후 성능 (팀 득실차 기준)
python data/validate_allnba.py             # All-NBA 일치율
python data/exp_hybrid.py                  # 비율 vs 개수 실험
python data/build_projection.py            # 다음 시즌 선수 예측 + 범위·도달 확률
python data/fetch_team_data.py             # 팀 ORtg/DRtg(1978~) + 2026-27 로스터
python data/build_team_projection.py       # 팀 레이팅 백테스트 + 2026-27 순위 예측
python data/exp_team_features.py           # 드래프트 순번·로스터 연속성 실험 (채택 안 함)
python data/build_site.py                  # 정적 사이트 빌드 → site/
python data/serve_site.py                  # 로컬 미리보기 → localhost:8000
python data/make_demo_gif.py               # README 데모 GIF ← docs/screens/
python data/build_report.py                # 상세 보고서 PDF ← docs/REPORT.md
```

```
data/    파이프라인·검증 스크립트, 페이지 템플릿
site/    배포본 (Vercel이 이 폴더를 루트로 서빙, push 시 자동 배포)
docs/    상세 보고서(REPORT.md·PDF), 데모 GIF와 원본 스크린샷
```
